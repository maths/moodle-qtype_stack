ASCIIMath Syntax

\`x^2\`
Wrap inline ASCIIMath in backticks.
\`a_n\`
Use underscores for subscripts.
\`(a+b)/(c+d)\`
Use parentheses to make fractions clear.
\`sqrt(x)\`
Square roots use function notation.
\`sin(theta)\`
Common functions and Greek names are recognised.
\`sum_(i=1)^n i\`
Lower and upper limits use subscript and superscript.
\`int_0^1 x^2 dx\`
Integrals use the same limit notation.
\`[[a,b],[c,d]]\`
Matrices are nested lists.
\` on its own line
Use a pair of standalone backticks for a displayed, multiline ASCIIMath block.

Filters And Extractors

  • Markdown is rendered for display, with ASCIIMath transformed for MathJax.
  • Calculations inside {@2^2 + 1@} are evaluated by the calculation filter.
  • Markdown needs a blank line between paragraphs or displayed blocks.
  • The demo extracts the last Answer: line, the last calculation result, all Step n = lines, and coefficient lines a = and b =.
  • Calculation functions include sin, cos, sqrt, log, mean, sum, and prod. Trigonometric functions use radians.
  • Omit maxWidth for unbounded horizontal resizing, or set it to cap the generated block.
