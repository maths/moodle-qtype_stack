Row and column vector notation available in every question. Use `vec_convert` to obtain
ordinary Maxima matrices for arithmetic and answer tests.

For convenience, `c(...)` and `r(...)` are aliases for `column_vector(...)` and `row_vector(...)`.
Enable them by adding `stack_linear_algebra_declare(true)` to the question variables. They evaluate
to the full forms, so expressions, inputs and answer tests use the same vector values.
Contributed libraries that previously enabled this notation continue to enable the aliases.
